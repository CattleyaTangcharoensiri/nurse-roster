# จัดตารางเวรพยาบาล

เครื่องมือจัดตารางเวรพยาบาลแบบออฟไลน์ — เปิดในเบราว์เซอร์ ไฟล์เดียว ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต

**เปิดใช้งาน:** <https://cattleyatangcharoensiri.github.io/nurse-roster/>
(หรือดับเบิลคลิก `dist/index.html` ในเครื่อง)

---

## เริ่มใช้เร็ว ๆ (7 ขั้น)

1. **เลือกเดือน/ปี** ที่หัวมุมซ้าย (พ.ศ.) — ระบบปรับจำนวนวันให้เอง
2. **ตั้งค่ากติกา** บนแถบเครื่องมือ
   - `คน/กะ` — จำนวนคนที่ต้องขึ้น ช / บ / ด ในแต่ละวัน
   - `หยุด O+R/คน` — โควตาวันหยุดต่อคนทั้งเดือน · ติ๊ก **เป๊ะ** = ห้ามขาด/เกิน
   - `2 กะ/วัน ≤/คน` — เพดานจำนวนครั้งที่คนหนึ่งขึ้น 2 กะในวันเดียว
3. **เพิ่มพยาบาลให้ครบ** ด้วยปุ่ม `+ พยาบาล` — ดูการ์ด **คำแนะนำ** ในรายงานว่าเดือนนี้ควรใช้กี่คน
4. **ล็อกล่วงหน้า** วันลา / อบรม / วันที่ต้องการ (ดูวิธีในตารางด้านล่าง)
5. กด **จัดตารางอัตโนมัติ**
6. เปิด **รายงาน** — ป้ายเขียว "จัดได้" = เสร็จ · ถ้าไม่ ทำตามคำแนะนำในรายงาน
7. **บันทึก JSON** (ไว้แก้ต่อทีหลัง) และ **ออก Excel** (ไว้แจก / พิมพ์)

> อยากเห็นตัวอย่างตารางที่จัดครบสมบูรณ์ กด **โหลดตัวอย่าง**

---

## สัญลักษณ์

| | ความหมาย | | ความหมาย |
|---|---|---|---|
| **ช** | เวรเช้า | **O** | หยุด (ระบบเติมให้ครบโควตา) |
| **บ** | เวรบ่าย | **V** | ลา |
| **ด** | เวรดึก | **T** | อบรม |
| **R** | หยุดที่กำหนดเอง | **ช+บ / บ+ด** | ขึ้น 2 กะในวันเดียว |

---

## แก้ตารางด้วยมือ

| ทำ | ได้ผล |
|---|---|
| **คลิก** ช่อง | วนค่า: ว่าง → ช → บ → ด → R → O → V → T |
| **คลิกขวา** ช่อง (มือถือ = แตะค้าง) | เมนูเลือกค่า (มี ช+บ, บ+ด ด้วย) |
| **Shift + คลิก** ช่อง | ล็อก / ปลดล็อก — ช่องที่ล็อก "จัดอัตโนมัติ" จะไม่แตะ |
| **คลิกขวา** ที่ชื่อพยาบาล | กำหนดว่าคนนี้ขึ้นได้เฉพาะกะไหน |
| **ดับเบิลคลิก** ชื่อ | เปลี่ยนชื่อ |
| ชี้ที่ชื่อ แล้วกด **×** | ลบแถว |
| **Ctrl + Z** | ย้อนกลับ |

**ล็อกวันลาล่วงหน้า:** คลิกช่องให้เป็น `V` (หรือ `R` / `T`) แล้ว **Shift+คลิก** ช่องนั้นเพื่อล็อก — จัดอัตโนมัติจะเก็บไว้ให้

---

## รายงาน (ปุ่ม "รายงาน")

- **คำแนะนำ** — เดือนนี้ด้วยจำนวนคน/โควตาที่ตั้งไว้ ควรปรับอะไร (เพิ่ม/ลดคน, เปลี่ยนโควตา) พร้อมตาราง "คนกี่คน → ต้องขึ้น 2 กะ/วัน กี่ครั้ง"
- **ความเป็นไปได้** — กะที่ต้องการทั้งเดือน เทียบกับกำลังคนที่มี
- **คนไม่พอ/เกิน** — วัน/กะ ที่คนยังไม่ครบ
- **ผิดกฎ** — จุดที่ละเมิดกติกา

---

## กติกาที่ระบบตรวจให้

- **ดึกต่อเช้า ห้ามเด็ดขาด** — วันนี้ขึ้น ด พรุ่งนี้ห้ามขึ้น ช
- **2 กะ/วัน** — ได้เฉพาะ ช+บ กับ บ+ด · คู่อื่นระบบไม่ให้
- ด ติดกันไม่เกิน 2 คืน · ทำงานติดกันไม่เกิน 5 วัน · หยุดติดกันไม่เกิน 2 วัน
- โควตาวันหยุด R+O ต่อคน (ตามที่ตั้งไว้)

ปรับตัวเลขกติกาเมื่อไร ถ้าตารางจัดเต็มอยู่แล้ว ระบบจะจัดใหม่ให้ทันที

---

## ท้ายตาราง (แถวสรุป)

รวม ช / บ / ด ต่อวัน · จำนวนคนขึ้นเวรวันนั้น · จำนวนคนหยุด R+O ต่อวัน

---

## ข้อควรรู้

- **ไม่มีบันทึกอัตโนมัติ** — ต้องกด **บันทึก JSON** เอง (ไฟล์ `.json` เอาไว้เปิดกลับมาแก้ต่อได้)
- **กด "จัดตารางอัตโนมัติ" = ล้างช่องที่ไม่ได้ล็อกทิ้งทั้งหมด แล้วจัดใหม่จากศูนย์** (เก็บเฉพาะช่องที่ล็อก / ลา / อบรม) — กดกี่ครั้งก็ได้ผลเหมือนเดิม
- **ออก Excel / ออก CSV** ได้ไฟล์จริงเปิดใน Excel ได้เลย · **พิมพ์** สั่งพิมพ์หน้าตารางได้ตรง ๆ
- ใช้ได้ทั้งคอม แท็บเล็ต มือถือ

## สำหรับผู้พัฒนา

```
npm test        # รันเทสต์
npm run build   # รวมเป็น dist/index.html ไฟล์เดียว
```

โค้ด engine อยู่ที่ `src/engine/` (model / analyze / solver / io / csv / xlsx) — JS ล้วน ไม่มี dependency
UI อยู่ที่ `src/ui/` · `build.mjs` รวมทุกอย่างเป็นไฟล์เดียวออฟไลน์
